# 🍳 Recipe Management Website

A modern and user-friendly **Recipe Management Web Application** built as a hackathon project.  
The application uses **Supabase** for authentication and data management, allowing users to securely create and manage their recipes.

## 📌 Project Overview

This project is a recipe-based web application where users can create an account, log in securely, access their dashboard, and add their own recipes.

The main goal of this project is to provide a simple and interactive platform where authenticated users can manage and share recipe information.

## ✨ Features

- 🔐 **User Authentication**
  - User Signup
  - User Login
  - Secure authentication using Supabase

- 📊 **Dashboard**
  - Personalized dashboard after login
  - Easy navigation to recipe management

- 🍽️ **Recipe Management**
  - Add new recipes
  - Store recipe information using Supabase
  - Display recipes on the recipe page

- 🗂️ **Recipe Page**
  - View available recipes
  - Organized recipe information
  - Easy-to-use interface

- 🔒 **Authenticated User Access**
  - Users must log in before accessing recipe management features
